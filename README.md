# Metrostroi Dedicated Save

Server-side addon for [Metrostroi](https://steamcommunity.com/sharedfiles/filedetails/?id=261801217) (Garry's Mod) that saves and restores the state of a dedicated server: trains, track switches and player positions.

*Серверный аддон для Metrostroi: сохраняет и восстанавливает состояние выделенного сервера — составы, стрелки и позиции игроков. Описание на русском ниже.*

## Что сохраняется

- **Составы**: все вагоны, их порядок и сцепки, позиция на карте, номер, раскраски и внешний вид кабины (панель АРС, КВ, БПСН и т. д.).
- **Состояние вагонов**: реле, тумблеры, автоматы, реверс, БВ, пневматика (давления, концевые краны, двери), батарея, АРС/АЛС, пломбы.
- **Стрелки**: положение всех стрелок карты, включая переведённые вручную.
- **Игроки по SteamID**: позиция и взгляд; если игрок сидел в кабине — вагон и место. При заходе на сервер игрок появляется там же.
- **Владельцы вагонов** по SteamID (для ререйла и других действий, доступных владельцу).

Составы восстанавливаются **стоящими и заторможенными** — скорость не сохраняется. Силовая электрика (токи, реостатный контроллер, двигатели) стартует с нуля, как у стоящего поезда.

## Установка

Скопировать (или `git clone`) папку в `garrysmod/addons/`, например:

```
garrysmod/addons/metrostroi-dedicated-save/lua/autorun/server/metrostroi_save.lua
```

Нужен Metrostroi. Аддон работает только на сервере, клиентам ничего ставить не нужно.

## Команды

Из консоли сервера или в игре (только админ):

| Команда | Описание |
|---|---|
| `ms_save [имя]` | Сохранить состояние (по умолчанию `manual`) |
| `ms_load [имя]` | Удалить текущие поезда и загрузить сохранение (по умолчанию — автосейв текущей карты) |
| `ms_saves` | Список сохранений |
| `ms_autosave_interval <сек>` | Интервал автосохранения, `0` — выключить (по умолчанию 900 = 15 мин) |
| `ms_autoload 0/1` | Загружать автосейв при старте сервера (по умолчанию 1) |

- Автосохранение — каждые `ms_autosave_interval` секунд и при выключении сервера, в файл `autosave_<карта>`.
- При старте сервера автосейв текущей карты загружается автоматически.
- Файлы лежат в `garrysmod/data/metrostroi_saves/`.

> Автосохранение при выключении срабатывает, только если сервер закрыт командой `quit`. При закрытии окна крестиком останется последнее периодическое автосохранение.

## Как это работает

- Вагоны создаются заново и ставятся на рельсы через `Metrostroi.RerailTrain`, как это делает спавнер, затем сцепляются.
- Числовые поля систем вагона сохраняются целиком; таймеры сохраняются как «сколько секунд назад» и пересчитываются при загрузке.
- Каждая восстановленная система проходит пробный такт и 60 секунд работает под защитой: если она падает с ошибкой, её состояние сбрасывается к заводскому, а не ломает весь вагон. Сбросы пишутся в консоль сервера (`[MS Save] System ... reset to default`).

## Ограничения

- Лучше сохраняться на прямом участке и заторможенным. В крутой кривой вагоны при загрузке могут дёрнуться; на уклоне поезд с отпущенными тормозами покатится.
- Проверено на 81-717/714 (МВМ). Другие серии должны работать, но могут потребовать доработки.
- С Turbostroi не проверялось: при включённом Turbostroi системы считаются в отдельном потоке и могут не восстановиться.

## Для других аддонов

Своё состояние можно хранить в сейве через хуки:

```lua
hook.Add("MetrostroiSave_Save", "myaddon", function(ext, cars, index)
    ext.myaddon = { ... }        -- вагоны — номерами index[car], не энтити
end)
hook.Add("MetrostroiSave_Load", "myaddon", function(ext, cars, savedAt)
    -- cars[n] — новая энтити вагона n; savedAt — os.time() сохранения
end)
```

Так, например, [metrostroi-dispatcher](https://github.com/poproshaikin/metrostroi-dispatcher) сохраняет наряд и сдвигает график на время перерыва.
